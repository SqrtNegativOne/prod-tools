A collection of Python scripts that help me maintain productivity every day.

- Watchdawg: ensures the apps / scripts / watchmen that ensure my productivity are always running. Who watches the watchmen? The dawg in me.
- App blocker: helps me avoid doing work directly or getting distracted before I get my priorities straight.
- Daily opener: launches the latest diary page in my Notion journal database.
- Window limiter: closes windows of certain apps when they exceed a limit. Currently just for firefox.
- Taskbar autohide: doesn't really work, sorry.

I moved this into its own repo because it grew too large for a single script.
- Shutdown enforcer: forces me go to sleep instead of working through the night.
